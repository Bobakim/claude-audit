## 페이지 변환 공식 (검증됨)

```
PDF 페이지 번호 = 사례집 인쇄 페이지 번호 + 6
```

- 사례집 앞부분(표지·목차·일러두기, 인쇄 페이지 번호 없음)이 PDF 페이지 1~7을 차지하고, 본문 인쇄 페이지 "-2-"가 PDF 페이지 8부터 시작
- **3개 챕터 경계(제1→2장, 제3→4장 등)에 걸쳐 검증 완료**: 사례1(인쇄2→PDF8), 사례33(인쇄78→PDF84), 사례35(인쇄84→PDF90) 모두 정확히 +6로 일치. 각 장 시작 전의 장표지(제N장 divider)는 인쇄 페이지 번호가 매겨지지 않지만 PDF 물리 페이지는 그대로 차지하므로, 오프셋이 챕터를 넘어가도 흔들리지 않음
- **추가 검증 (사례 18~26 처리 시)**: 제2장 전체(사례18 인쇄44→PDF50 ~ 사례26 인쇄63→PDF69)와 제2→3장 경계(사례26 종료 후 장표지 진입, 사례27 인쇄66→PDF72)에서 모두 헤더가 정확히 일치함을 렌더링으로 확인. 사례18~26 9건 전건에서 공식이 한 번도 어긋나지 않음
- **추가 검증 (사례 27~32, 34 처리 시)**: 제3장 나머지 전건(사례27 인쇄66→PDF72, 사례28 인쇄68→PDF74, 사례29 인쇄70→PDF76, 사례30 인쇄72→PDF78, 사례31 인쇄74→PDF80, 사례32 인쇄76→PDF82, 사례34 인쇄81→PDF87)에서 헤더가 모두 정확히 일치함을 렌더링으로 확인. 사례34 종료 직후(PDF89)에서 제4장 장표지가 시작되는 것도 확인해, 사례35(인쇄84→PDF90) 시작점과 정확히 맞물림 — 제3→4장 경계에서도 공식이 흔들리지 않음. 이로써 제3장 8건(사례27~34) 전건이 공식과 실제 헤더가 일치함을 확인
- **추가 검증 (사례 36~52 처리 시)**: 제4장 나머지 16건 전건(사례36 인쇄86→PDF92 ~ 사례52 인쇄122→PDF128)에서 헤더가 모두 정확히 일치함을 렌더링으로 확인. 사례52 종료(PDF123) 직후 백지 1쪽을 거쳐 제5장 장표지가 시작되는 것도 확인해, 사례53(인쇄126→PDF132) 시작점과 정확히 맞물림 — 제4→5장 경계에서도 공식이 흔들리지 않음. 이로써 제4장 17건(사례35~52) 전건이 공식과 실제 헤더가 일치함을 확인. 단, 사례36의 정보 박스 "쟁점 분야" 필드에는 "선급금"이라고 인쇄되어 있으나 본문·사례명은 모두 "대여금"이어서, 직전 사례(#35)의 필드가 편집상 잘못 남은 것으로 추정됨(카드에는 [확인필요]로 표기)
- **추가 검증 (사례 53~62 처리 시, 최종 배치)**: 제5장 전건(사례53 인쇄126→PDF132 ~ 사례62 인쇄145→PDF151)에서 헤더가 모두 정확히 일치함을 렌더링으로 확인. 마지막 사례(#62, FSS/2405-14)가 PDF쪽 151(문서의 마지막 물리 페이지)과 정확히 맞물려 종료됨을 확인 — **문서 전체 62건에 대해 "PDF쪽 = 인쇄쪽 + 6" 공식이 한 번도 어긋나지 않고 처음부터 끝까지 유효함이 확정됨**
- 각 사례는 인쇄 기준 다음 사례 시작 페이지 직전까지 이어짐 (표 하단 "PDF 시작" 열 참고, 종료 페이지는 다음 행의 PDF 시작 − 1, 단 챕터 마지막 사례는 장표지 진입 전까지)

## 사례 정보 박스 구조 (모든 사례 공통)

각 사례는 4~5개 섹션으로 구성됨: `1 회사의 회계처리` → `2 회계기준 위반 지적 내용` → `3 지적 근거 및 판단 내용` → `4 감사절차 미흡사항` → (`5 시사점`, 있는 경우만).

상단 정보 박스는 **쟁점 분야 / 관련 기준 / 결정일 / 회계결산일** 4개 필드만 제공한다. **`docs/PRD.md` §6.4가 요구하는 "조치수준" 필드는 이 출처에 존재하지 않는다** — 정보 박스에도, 본문 서술에도 조치수준(경고/시정요구/과징금/검찰고발 등)을 명시하는 부분이 없다. 카드 작성 시 이 필드는 항상 `[확인필요]`로 남겨야 하며, 필요하면 금감원 별도 "조치내역" 공시자료와 대조해야 채울 수 있다.

회사명은 전 사례에서 `A사`로 익명 처리되어 있다 (사례별로 다른 회사이지만 지칭은 모두 A사로 동일 — 카드에서 실명 추정 절대 금지, 사례 ID로만 구분).
